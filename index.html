About This Presentation

A platform-team guide to the three autoscalers Aurora runs, and how they fit together. This presentation covers:

  • VPA: right-sizing pod CPU/memory requests
  • KEDA: event- and schedule-driven replica scaling, including scale-to-zero
  • Karpenter: just-in-time node provisioning and consolidation
  • How the four scaling axes layer together
  • Interactions, conflict rules, and anti-patterns

Quick Start

To build the presentation PDFs locally:

make pdf       # Build English and French PDFs
make preview-en  # Preview English slides in browser
make preview-fr  # Preview French slides in browser

To generate the HTML site for GitHub Pages:

make html      # Build HTML site to docs/
