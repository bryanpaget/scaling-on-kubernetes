About This Presentation

This presentation provides comprehensive guidance on using Vertical Pod Autoscaler (VPA) on the Aurora Platform. It covers:

  • What VPA is and how it differs from HPA
  • Recommended VPA modes for production
  • Integration with HPA and KEDA
  • Production guardrails and anti-patterns
  • Troubleshooting common issues

Quick Start

To build the presentation PDFs locally:

make pdf       # Build English and French PDFs
make preview-en  # Preview English slides in browser
make preview-fr  # Preview French slides in browser

To generate the HTML site for GitHub Pages:

make html      # Build HTML site to docs/
